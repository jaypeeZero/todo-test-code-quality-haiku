# ideology/no-swallowed-errors

`src/logging.js` · `logAction` · a9d7f79 → prism-style simulation

**Rule:** Let this error propagate, or recover so the surrounding code can continue.

## Before

```js
  try {
    await insert('user_logs', logRecord);
  } catch (error) {
    console.error('Failed to log action:', error);
  }
```

## After

```js
  try {
    await insert('user_logs', logRecord);
  } catch (error) {
    console.error('Failed to log action:', error);
    throw error;
  }
```
